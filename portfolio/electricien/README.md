# Site Web Artisan Électricien

Site vitrine professionnel pour un artisan électricien, optimisé pour la conversion, le SEO local et le responsive design.

## 🎯 Objectifs

- Convertir les visiteurs en clients (appels, devis, rendez-vous)
- Inspirer confiance et professionnalisme
- Optimiser pour le SEO local (Paris et Île-de-France)
- Garantir une excellente expérience utilisateur sur tous les appareils

## 📁 Structure du Projet

```
/
├── index.html              # Page d'accueil
├── services.html           # Page services (Installation, Dépannage, Normes, Domotique)
├── a-propos.html          # Page À propos (expérience, valeurs, certifications)
├── avis.html              # Page avis et témoignages clients
├── contact.html           # Page contact (formulaires, carte)
├── mentions-legales.html  # Mentions légales
├── politique-confidentialite.html  # Politique de confidentialité
├── rgpd.html              # Informations RGPD
├── css/
│   └── style.css          # Styles CSS responsive (Mobile-First)
├── js/
│   └── main.js            # JavaScript (menu mobile, formulaires)
└── img/
    └── logo.png           # Logo de l'entreprise (à remplacer)
```

## 📱 Responsive Design

Le site est conçu en Mobile-First avec des breakpoints :
- Mobile : < 768px
- Tablet : ≥ 768px
- Desktop : ≥ 1024px

## 📝 Personnalisation

### Informations à remplacer

1. **Téléphone** : Remplacer `+33123456789` et `01 23 45 67 89` dans tous les fichiers
2. **Email** : Remplacer `contact@electricien-pro.fr`
3. **Adresse** : Mettre à jour l'adresse dans les pages légales
4. **SIRET/RCS** : Compléter dans `mentions-legales.html`
5. **Logo** : Remplacer `img/logo.png` par votre logo
6. **Carte Google Maps** : Mettre à jour l'URL de la carte dans `contact.html`
7. **Zone d'intervention** : Adapter selon votre zone réelle

### Couleurs

Les couleurs sont définies dans `css/style.css` via les variables CSS :

```css
--color-primary: #1e3a5f;      /* Bleu foncé */
--color-secondary: #f4a261;    /* Orange */
--color-accent: #2a9d8f;       /* Turquoise */
```
